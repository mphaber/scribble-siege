# Scribble Siege

A paper flick-combat game: flick your fighters across a sheet of notebook paper and blow up the enemy base. Space, Knights, and Tanks themes, 1P vs CPU or 2P pass-and-play.

Play: https://mphaber.github.io/scribble-siege/

This folder is the multi-file snapshot of the game: `index.html` plus the complete `assets/` folder (51 WebP images — the three board plates and every piece sprite), referenced by relative paths. Serve or host the folder as-is; no build step.
